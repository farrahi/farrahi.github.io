# Open Topics

I am currently offering several topics for **MSc theses, internships, and research projects** in the areas of machine learning, data science, sports, health, and digital technologies.

## MSc Theses & Internships

### In-context learning for tabular data using tabular foundation models

**Type:** MSc thesis / Internship
**Area:** Machine Learning, Large Language Models, Tabular Data
**Location:** TU Dortmund University

Large Language Models (LLMs) have demonstrated an impressive ability to perform new tasks from examples provided directly in the input, a capability known as **in-context learning**. More recently, foundation models specifically designed for tabular data have emerged.

This project will investigate how effectively tabular foundation models can perform prediction and classification tasks using in-context learning. The project may focus on questions such as:

* How well do tabular foundation models perform with zero-shot and few-shot learning?
* How does the selection and number of examples affect performance?
* How does in-context learning compare with conventional machine learning methods?
* How robust are these approaches across different datasets?
* Can domain-specific examples improve prediction performance?

**Possible methods:**
Machine learning, tabular foundation models, in-context learning, prompt engineering, zero-shot learning, few-shot learning, benchmarking.

### Large Language Models for Wearable Sensor Data

**Type:** MSc thesis / Internship
**Area:** Large Language Models, Wearables, Digital Health

This project investigates how Large Language Models can be used to analyse and interpret data collected from wearable sensors.

Potential research questions include:

* Can wearable sensor data be represented in a format suitable for LLMs?
* Can LLMs classify physical activities from wearable data?
* Can LLMs identify behavioural patterns from time-series data?
* How does LLM-based analysis compare with conventional machine learning and deep learning?

**Possible methods:**
LLMs, prompt engineering, time-series analysis, machine learning, deep learning, wearable sensors.

---

### Machine Learning for 24-hour Movement Behaviour

**Type:** MSc thesis / Internship
**Area:** Physical Activity, Sleep, Sedentary Behaviour, Machine Learning

The 24-hour day consists of different movement behaviours, including sleep, sedentary behaviour, light physical activity, and moderate-to-vigorous physical activity. This project will investigate how machine learning can be used to characterize and predict these behaviours.

Possible directions include:

* Identification of behavioural profiles
* Prediction of movement behaviour patterns
* Clustering and unsupervised learning
* Compositional data analysis
* Integration of wearable sensor data with demographic and health information

**Possible methods:**
Machine learning, clustering, compositional data analysis, statistical modelling, wearable sensor data.
